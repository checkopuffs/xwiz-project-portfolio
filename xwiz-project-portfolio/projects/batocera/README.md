# Batocera gaming laptop repurpose

**Status:** Booting, game launch issue resolved for a PS2 game after fixing missing BIOS configuration. Collection expansion is only a plan.

## Hardware

Dell Latitude 7490, Core i7, 16 GB RAM, 256 GB SSD.

## Troubleshooting story

A PlayStation 2 title initially showed a black screen and returned to the game selection screen. Initial launcher logs were not conclusive. **Batocera's missing-BIOS check** revealed required BIOS files, and after adding a legitimately obtained matching BIOS file, the game launched.

## What this demonstrates

Linux troubleshooting, verifying platform prerequisites, reading application diagnostics, storage planning and repurposing older business hardware.

Future work: curate a collection of properly licensed/open games and homebrew software while staying within the existing SSD capacity. No copyrighted BIOS or commercial ROM files are included in this repository.
