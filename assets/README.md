# Media placeholders and checklist

Add only images/screenshots you own or have permission to publish. Recommended shots:

- Finished portable radar sensor and display (no faces or location info).
- Cropped XWiz Telegram bot help/status view (blur chat IDs, usernames, IPs, and tokens).
- Homelab rack photo and a *sanitized* dashboard crop.
- Speaker enclosure CAD render clearly labeled *prototype*.
- Buddy Mini on-screen prototype clearly labeled *simulator*.

Keep project photos small (~1600px long edge, optimized JPEG/WebP), and link them from the appropriate project README.
